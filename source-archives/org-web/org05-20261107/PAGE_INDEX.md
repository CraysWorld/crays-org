## Use the index

1. Choose the section, then use your browser’s Find command for the route or a word in it.
2. Open the route link to inspect its original JSON. Every source link is pinned to commit c3007f8d63bf7a633d7e0669cc96f0b5c31bc091.
3. For a source change, keep the route-to-file relationship in [data/routes.json](https://github.com/CraysCircle/crays-org/blob/c3007f8d63bf7a633d7e0669cc96f0b5c31bc091/source-archives/org-web/org05-20261107/data/routes.json) and the linked original page together.

The registry source is 204,948 bytes with SHA-256 579e544d5fb84a52b139c1167a3ba4caa2b96235e32668c7f488c2bdf1069fb4. Its 1,837 entries identify 1,837 distinct page JSON files. This is navigation for the recorded source snapshot; current deployment and rights information remain in the [archive guide](README.md) and [source capture](source-capture.json). Article/page data and media are separate from the file-specific own-code license scope.
